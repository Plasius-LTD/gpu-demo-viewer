# Composite definitions for host applications

Tracked work: site Story #2321 and viewer Task #83.

Expose the four existing qualified arrangements through the typed package
subpath `@plasius/gpu-demo-viewer/model-library/studies`. A pure
`compositeStudyDefinitions()` function returns fresh definitions containing the
stable key, source keys, bottom-centre anchors, longest dimensions, yaw and review
copy. Extract the existing definitions without changing any value. The workshop
and website then share one owner for placement.

The module must import no renderer, DOM, acquisition helper or local-review
bootstrap, and perform no I/O. Return independent arrays so consumer edits do not
alter another call or the workshop. Hosts resolve keys against their own admitted
catalogue, translate display copy, retain every credit/integrity entry, and apply
their capability/feature controls before calling released shared scene inspection.
The definitions are layout data, not entitlement decisions or additional models.

Parent Feature site#1170 / Epic site#2271 and inherited flag
`gpu-demo.scene-fidelity.enabled` apply. The local review gate stays unchanged;
public access is governed by the website's existing studio capability and GPU
runtime. Rollback uses those stored rules or reverts the consuming package version.

Before implementation, require tests for the supported export, its type/file
contract, exact unchanged scene membership and placement, isolated return values,
and continued workshop composition. Keep existing rendering/credit tests. Update
consumer README, Unreleased changelog and ADR0006. Run all package validation and
coverage with changed-source LCOV, publish only through approved main/production
CD after CI, and compare npm contents to the attested release artifact before
the site consumes the new export.
